# 사고지점 데이터 확보 및 변환 기록

확인일: 2026-10-22 (한국 시간). 실제 사고 원본 수집일: 해당 없음.

공식 메타데이터: https://www.data.go.kr/catalog/15029185/fileData.json
원본 안내: https://www.data.go.kr/data/15029185/fileData.do
데이터명: 전국교통사고다발지역표준데이터.
공식 메타데이터에서 확인한 이용 조건: 이용허락범위 제한 없음.
확인한 항목: 사고지역관리번호, 사고연도, 사고유형구분, 사고지역위치명,
사고건수, 위도, 경도, 사고다발지역폴리곤정보 등.
메타데이터 수정일은 사고 기준 연도와 다르다. 기준 연도는 각 원본 행의 사고연도를 사용한다.

이번 작업에서는 용인시 원본 CSV 행과 좌표계 설명을 확보하지 못했다.
따라서 실제 용인시·수지구·죽전 사고 현황이나 데이터 포괄 범위를 주장하지 않는다.
API 연동과 인증키 저장은 구현하지 않았다. 외부 호출 없이 CSV로 분석할 수 있다.

## 매핑

| 확인한 원본 컬럼 | 내부 필드 |
|---|---|
| 사고지역관리번호 | hotspot_id |
| 사고지역위치명 | location_name |
| 위도 / 경도 | latitude / longitude |
| 사고유형구분 | accident_type |
| 사고건수 | accident_count |
| 사고연도 | reference_year |

내부 필드는 실제 공공데이터 컬럼으로 가정하지 않는다. 원본에 내부 컬럼이 이미 있으면 우선한다.
source_name, source_url, is_demo가 원본에 없으면 결측으로 유지한다.
실제 자료를 확보하면 원본 주소·다운로드일·좌표계·연도별 포함 지역·이용 조건을 확인하고
source_name/source_url/is_demo=false를 명시한 파생 CSV와 이 문서를 함께 갱신해야 한다.
현재 어댑터는 WGS84 위경도(십진도) 입력만 지원한다. 투영 좌표는 입력 전에 변환해야 한다.
범위 검사만으로 좌표계를 증명할 수 없으므로 업로더가 원본 좌표계를 확인해야 한다.

`data/regional/demo_hotspots.csv`는 수지·죽전 일대의 임의 좌표 2개다.
실제 사고지점이 아니며 사고유형·건수·연도·원본 URL은 결측이다.
is_demo=true, source_name=프로젝트에서 임의 생성으로 표시한다.
시연 자료도 실제 자료와 동일한 검증을 거친다. 기본 화면에서는 사용하지 않는다.

## 근접 분석의 한계

이벤트 최대 절대 가속도 시점의 좌표와 사고지점 중심 간 Haversine 거리(지구 반지름 6,371km)를 계산한다.
설정 반경 이내의 모든 지점을 반환한다. 하나의 이벤트가 여러 지점에 연결될 수 있으므로
피드백은 고유 event_id 수로 집계한다. 폴리곤, 도로망, 방향, 사고 인과관계는 분석하지 않는다.
출처 미확인 또는 가상 자료가 포함되면 화면에서 경고한다.
